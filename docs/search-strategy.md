# Search-led content strategy

User instruction, October 6, 2026: check what people are searching for and write blogs for those needs only.

## Evidence collected

Dated Google autocomplete responses, US region and English language, are saved in search-demand.json. Google explains that predictions can reflect real searches as well as word patterns on the web: https://support.google.com/websearch/answer/7368877. This is directional intent evidence, not a monthly-volume estimate or a difficulty score. The connected Ahrefs API returned Insufficient plan; no volumes or ranking difficulties have been invented.

The generic phrase clipping guide has mixed intent, including animal grooming and hair clippers. Restrict coverage to video, streamer, podcast, creator, campaign, and relevant editing-tool intent.

## Priority intents and destinations

| capcut captions not working; capcut captions not showing | Separate generation, display, and export failures | Write a focused troubleshooting guide |

These priorities are based on relevance and gaps in existing coverage, not a claimed volume ranking. Preserve existing useful supporting guides and canonical URLs. Do not create a separate article for every keyword variation.

## Required gate for future publishing

Before a new blog, record the actual query, evidence source, checked date, region, intent, existing-page overlap, proposed destination, and useful difference. A seed echoed unchanged without relevant suggestions is not enough. Use Search Console impression/query data and Ahrefs metrics when available. Public search suggestions and actual live results may supply directional evidence; label their limits. Creator videos are sources to answer those questions, not automatic triggers for new articles.

Prefer a substantive update to the existing page when two terms have the same intent. Each new page needs a distinct task, original explanation or diagnostic example, official sources where relevant, and contextual internal links. Validate, deploy, and check the live result using the publishing playbook.
